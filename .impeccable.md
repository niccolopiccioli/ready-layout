## Design Context

### Users
Three overlapping user types: freelancers/agencies building sites for clients, founders and makers launching their own products, and SMBs without a technical team who want to manage their site themselves. They open the editor to get work done — not to be wowed by the tool itself. The editor is professional territory: users may spend hours inside it. The interface should disappear behind the work.

### Brand Personality
**Three words**: measured · capable · deliberate

The product should feel like a precision instrument — not a toy, not a SaaS marketing page, not an art project. Think Leica camera interface, Bloomberg Terminal clarity without the density, the typography in a Swiss engineering manual. Confidence without noise.

Emotional goals: users should feel competent and in control. The tool should not demand attention. Every interaction should feel inevitable.

### Aesthetic Direction
- **Theme**: system preference (light/dark via CSS `color-scheme: light dark`)
- **Light mode**: Near-white with a barely perceptible blue-gray tint. Sidebar panel slightly cooler than canvas. Borders are subtle — structure through spacing, not lines.
- **Dark mode**: Very dark, not pure black. Same tint direction. High contrast where it matters (active states, inputs in focus), low contrast everywhere else.
- **Accent**: Sage teal — `oklch(52% 0.15 155)` light / `oklch(70% 0.14 155)` dark. Not purple, not indigo, not the cyan-on-dark AI default. Appears rarely: active tabs, focused inputs, primary button.
- **Font**: Hanken Grotesk — clean grotesque, elliptical letterforms, feels precise and purposeful without being flashy. NOT Inter, NOT DM Sans.
- **Anti-references**: Generic SaaS (Notion-lite), gradient-text hero sections, glassmorphism, anything that looks "AI made this."
- **References**: Figma sidebar, Linear issue list, Vercel dashboard chrome, Raycast command interface.

### Design Principles
1. **Chrome disappears** — the editor UI should recede. The canvas is the product; the sidebar is the service.
2. **Precision over decoration** — field labels read like engineering specs (uppercase, tracked, small), not marketing copy.
3. **Space is hierarchy** — different sections have different breathing room. Not everything gets the same padding.
4. **Accent is rare** — the sage teal appears only on interactive state changes. Overuse kills its meaning.
5. **System follows user** — respect OS theme preference; never force a visual choice on the user.

# ReadyLayout

Visual no-code site builder. Drag-and-drop interface for assembling responsive web layouts without writing code.

Built with **Next.js** (App Router) and **TypeScript**.

## Stack

| Layer | Technology |
|-------|------------|
| Framework | Next.js (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
